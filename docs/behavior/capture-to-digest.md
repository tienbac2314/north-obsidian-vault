# Capture-to-growth behavior

## Direct capture

Write or paste into Obsidian. If destination is obvious, use it. Otherwise use `INBOX/Unsorted`. No required template, property, summary, or agent call.

Ordinary note remains ordinary. Only move to `INBOX/Pending Agent Review` when agent help is wanted.

## Agent review

Hermes proposes concise transformation:

- source or context;
- explanation in plain language;
- why it matters to current work;
- one example or caveat;
- one practice/next action;
- suggested links and optional PARA/ZETA destination.

Original stays unchanged until approval. User may accept, edit, reject, or leave pending. Stale proposal is regenerated rather than merged automatically.

## Weekly review

Review only useful/repeated items, not every note chronologically. Produce:

1. three strongest lessons in own words;
2. one repeated confusion, blocker, or pattern;
3. one thing applied/shipped/fixed;
4. one action or experiment for next week;
5. links to relevant project/area/permanent notes.

## Monthly review

Compress weekly notes into changed beliefs, demonstrated skills, recurring risks, abandoned ideas, and next deliberate practice. This is rereadable growth record.

## Optional Telegram

Later quick captures enter durable SQLite queue, then become a proposal or unprocessed inbox artifact. No LLM or OpenViking call precedes `Saved`.
