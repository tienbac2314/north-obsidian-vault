## Meaning

- `STAGING/Pending Agent Review` contains exact notes submitted for review.
- `STAGING/Agent Proposals` contains Hermes suggestions, never approval.
- `STAGING/Reviewed` contains completed review records, not automatic
  authorization to modify unrelated notes.

Review proposal content and its `Human review` block before acceptance.
