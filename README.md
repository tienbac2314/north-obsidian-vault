# Personal engineering workspace

Research and design for an Obsidian-first personal library that turns scattered learning into useful weekly insight and changed engineering practice.

## Current recommendation

- Obsidian Markdown is canonical human library and primary input.
- Dusk-inspired PARA/Zettelkasten structure stays optional; capture defaults to `INBOX/Unsorted`.
- `INBOX/Pending Agent Review` requests proposal, never direct overwrite.
- Hermes orchestrates; deterministic workspace service owns safe apply.
- Git provides audit/rollback; validated free sync and encrypted backup remain separate.
- OpenViking is later rebuildable agent-facing projection.
- 9Router handles permitted replaceable generation/VLM, not raw durability or fallback embeddings.
- Optional Telegram text/link capture commits with full-synchronous SQLite WAL before `Saved`; media gets separate metadata-pending and attachment-saved states.
